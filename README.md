# homebrew-tap

Homebrew tap for my tools.

```sh
brew install rojosinalma/tap/pawl
```

| Cask | What it is |
|---|---|
| `pawl` | [pawl](https://github.com/rojosinalma/pawl): make a repository's own tooling enforce a quality catalog, one way only |

The casks under `Casks/` are written by each project's release workflow.
